# Лендинг Камалов Дубай — как запускать

Nuxt 4. Node 22, npm.

## Разработка

```bash
cd site
npm install
npm run dev
```

Откроется на `http://localhost:3000`.
⚠️ На машине Марка порт 3000/3210 часто занят другими проектами — если открылся чужой сайт,
запускай с явным портом: `$env:PORT="4787"; npm run dev`

## Сборка и просмотр

```bash
npm run build
$env:PORT="4787"; $env:HOST="127.0.0.1"; node .output/server/index.mjs
```

## Проверка вёрстки

Оба инструмента работают на **системном Chrome** — браузер не скачивается.

```bash
# Скриншоты 1600 / 1280 / 390 px + автопоиск элементов, вылезающих за экран
node tools/shot.mjs

# Эффекты, которые видно только при прокрутке и наведении
node tools/scroll-check.mjs
```

Результат кладётся в `tools/shots/`. Перед показом Марку прогонять оба — переполнение по
ширине глазами на скриншоте не всегда заметно, а `shot.mjs` его называет поимённо.

## Правила, о которых легко забыть

- **RTL с первого дня.** Логические свойства (`margin-inline-start`, `padding-inline`,
  `text-align: start`) вместо `left`/`right`. Арабская версия — оплачиваемый второй этап.
- **`min-inline-size: 0`** на каждом flex/grid-контейнере с текстом, иначе длинная строка
  раздувает страницу вширь.
- **Ширина текста — `min(62ch, 100%)`**, не голые `ch`.
- **Дисклеймеры набираются тем же кеглем, что основной текст** — требование DHA, не вкусовщина.
